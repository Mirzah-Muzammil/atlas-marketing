# About page design

## Scope

Create an Atlas About page at `/about`. The shared application layout supplies the existing header and footer.

## Hero

Use the established secondary-hero structure.

- Left: the About statement, supporting copy, and three proof points: Six Years in the field, London Where we are based, and Free The OS, forever.
- Right: an editorial three-image collage that gives those proof points visual context. Use genuine photography or existing Atlas imagery, not illustrative icon cards.
- Preserve the dark Atlas theme, orange accent, global grid background, and existing title entrance treatment.

## Six principles

Use the approved asymmetric layout rather than a uniform card grid.

- Left column: heading, short explanation, and one editorial image.
- Right column: a two-column, three-row grid containing the six source principles and their descriptions.
- Use fine dividers and the same dark surface, white typography, and orange detail treatment as the marketing site.
- Do not use decorative icons. Each principle is a text-led editorial unit.

## Content and supporting sections

Use the reference About page as the source for its purpose statement, principles, team, honest metrics, three-horizon vision, founder note, and final CTA. Match Atlas components and layout patterns rather than copying the reference page's visual treatment.

## Verification

- Add About-page coverage for the hero proof points and all six principles.
- Run lint, typecheck, tests, and a production build.
